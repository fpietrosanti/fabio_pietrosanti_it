# fabio.pietrosanti.it

Personal profile site of Fabio "naif" Pietrosanti, hosted on GitHub Pages.

**Status:** planning. The new site is not built yet; the domain still points to the old
Blogger page, archived in [`archive/blogger-2026-09-16/`](archive/blogger-2026-09-16/).

## Principles

- **Three languages, same content:** English, Italian, Chinese (Simplified).
- **LinkedIn (English) is the master** for what LinkedIn holds: headline, About, experience.
  The site is realigned with it on the same monthly cadence as the LinkedIn translations.
- Everything LinkedIn cannot hold — talks, publications, security research, open source,
  press, communities — is maintained here.

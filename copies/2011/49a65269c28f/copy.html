GlobaLeaks is an open source software system intended to enable anonymous whistle-blowing.[2] The GlobaLeaks organization, in addition to developing a whistle-blowing software suite, aims to promote whistleblowing to the public.[3]

[edit] History

A prototype was announced on 6 September 2011[1] as an alpha release.[4]

[edit] Model

Globaleaks does not publish to the public. The organization invites anyone to install their software on their own computers, thus making it a node in a distributed private anonymous network. Whereas Wikileaks uses a centralized data distribution system similar Napster's, Globaleaks uses a shared download distribution system similar to BitTorrent's.[5]

[edit] Operation

A GlobaLeaks node utilizes Tor Hidden Services and Tor2web.[2]

[edit] Organization

GlobaLeaks is an independent organization made up of a globally distributed group of software developers.[4]

 TITLE

 Cisco Secure PIX Firewall Vulnerability

 Trust: 0.6

 sources:

 CNNVD: CNNVD-200012-075 

 DESCRIPTION

 Cisco Secure PIX Firewall 5.2(2) allows remote attackers to determine the real IP address of a target FTP server by flooding the server with PASV requests, which includes the real IP address in the response when passive mode is established. The Cisco PIX is a popular firewall network device. 
It is possible to configure the PIX so that it hides the IP address of internal ftp servers from clients connecting to it. It is not known what exactly causes this condition. 
This has been verified on versions 5.2(4) and 5.2(2) of the PIX firmware and probably affects other versions

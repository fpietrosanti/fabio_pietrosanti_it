# Archive of the old fabio.pietrosanti.it (Blogger)

Snapshot taken on **2026-09-16**, before the Blogger site is taken down and the domain
moves to GitHub Pages. This is source material for the new site, not the new site.

## What was online

At the time of the snapshot `fabio.pietrosanti.it` was a **Blogger** blog
(CNAME → `ghs.google.com`, DNS at EuroDNS), reachable over HTTP only.
It held a single long profile, in two versions:

| Version | URL | Date | Notes |
|---|---|---|---|
| Post «Something about me» | `/2013/08/something-about-me.html` | last updated **2013-10-27** | newest version, the one shown on the homepage |
| Page «Myself» | `/p/blog-page_7.html` | 2013-08-07 | older draft, slightly different wording |

## Files

```
content-post-2013-10.md   clean Markdown of the post (links preserved) — start here
content-page-2013-08.md   clean Markdown of the older page version
raw/index.html            homepage HTML as served
raw/2013-08-something-about-me.html
raw/p-blog-page_7-myself.html
raw/feed-posts.{atom.xml,json}   Blogger posts feed (full content)
raw/feed-pages.{atom.xml,json}   Blogger pages feed (full content)
raw/favicon.ico, raw/robots.txt, raw/sitemap.xml
```

There were no images in the content. The Blogger template assets (CSS/JS bundles from
blogger.com) were not archived: they aren't part of the content.

## Redaction

This repository is **public**. The personal phone number that appeared in the original
«Notice on communication security» section has been replaced with
`[phone number redacted]` in every file here. An unredacted copy is kept in a private
repository. Nothing else has been changed.

The Internet Archive was offline on the day of the snapshot, so no Wayback copies of
older versions were collected.
